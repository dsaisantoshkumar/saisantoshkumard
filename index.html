Conway’s Game of Life: Serial & MPI Parallel

Academic project, CSC 510 Operating Systems

A serial cellular automaton simulation becomes a bottleneck at large grid sizes.

  • Implemented Conway’s Game of Life in C with both a single process serial version and an optimized MPI parallel version.
  • Used halo row exchange between MPI ranks, broadcasting the initial grid with MPI_Bcast and synchronizing each generation with MPI_Sendrecv and MPI_Barrier.
  • Measured wall clock performance with MPI_Wtime and MPI_Reduce, showing the parallel version running roughly 3 times faster than the serial version on larger grids.
  • Added early termination once the board reached a stable, unchanging state, avoiding wasted iterations.
